# v16 正式大型升級：內容、閱讀介面、效能及自動品質驗收

完成於 2026 年 10 月 9 日。網站：https://tom-gpt65.github.io/ai-daily-intelligence/

## 範圍與基準

本次是使用者授權的**正式 v16 功能發布**，不同於平常的逐日新聞生成或測試。後續每日出稿、錯誤補正、歷史補檔與回歸測試不會因此自動升級版本號。網站不變更既有生字、答題、閱讀進度或匯出／匯入的 `localStorage` 鍵。

## 已完成的改善

### 1. 新聞內容與資料完整性

- 修正原先將「開放原始碼安全掃描」錯誤連接到生物實驗的問題；根本原因是模糊子字串分類，把 `General AI` 的片段當作 `gene`。
- 修正機器人技術報道的無關泛論；新版分類優先分析新聞標題的完整英文詞形，再以供應商類別為備援。
- 提供針對 software security／robotics 的領域專用閱讀分析，避免無關的科技、投資或生物研究模板。
- 更正已發布的 2026-10-09 文章（約 1,355 個英文單字），保留原本來源連結、理解題和歷史日期。歷史索引版本時間與字數同步。
- 移除閱讀正文中不應出現的 `arXiv:… Announce Type: … Abstract:` 原始 RSS 欄位，處理沒有完成的引述，並清理誤導性的技術性說明。
- 加入出版前內容品質守門：攔截原始 RSS 機器欄位、明顯的提示詞包裝、AI 自我聲明模板、失效字元；只接受有足夠來源標註、篇幅及離線字義的文章。**這是自動啟發式檢查，不代表所有句子已獲人工潤飾或每則事實已獨立查證。**

### 2. 每日文章真正有所不同

- 將無網絡也能生成的備援教材庫由 12 個主題提升至 24 個，每天固定抽取其中 10 個，日期可重現；相鄰日期不會重用相同的主題段落。
- 新主題包括私隱、原始來源、有效的人類監督、創作權利、無障礙、環境成本、競爭、跨語言表現、問責、就業、醫療與長期維護。
- 以來源對得上的題名命名教育閱讀，並清楚標示「非即時新聞」，不把原創教材當成當天新聞。
- 40 個模擬日期的備援文章長度介乎 1,242–1,264 個英文單字；全部保留七道閱讀題。
- 24 個主題加引言／結語共有約 818 個不同的英文可查詞形；補上所有缺漏的繁體中文離線詞義（**覆蓋率測試**不等於每個歧義詞義都經人工語境校正）。

### 3. 版面、字體及無障礙操作

- 新增獨立小型 `v16.css`，以裝置內建的繁體中文字體顯示介面，不使用外部網絡字型下載。
- 英文正文優先使用 iPad／macOS 可用的 Iowan Old Style，並有 Palatino、Georgia 後備；限制約 65ch 行寬、改善行距與自然換行。
- 手機閱讀字級約 17.5px，重要操作按鈕在窄螢幕保持至少 44px 的觸控高度；加強聚焦外框、縮放及段落跳轉可視性。
- 考慮 `prefers-reduced-motion`、列印版式、亮色／暗色與字詞解釋框高度限制，減少 Safari 裁切和互動困難。
- 以繁體中文實際功能名替換空泛英文標語，例如「每日 AI 英文深度閱讀」、「重點詞彙」、「新聞來源」、「英文閱讀理解」；移除不必要的零付費 API 宣傳。
- 來源品質與全文翻譯的第三方資料傳送提示仍保留，但改為按需要展開；不應為了減少畫面文字刪掉重要私隱與事實限制。

### 4. 保留狀態與瀏覽器功能

- 背景刷新不再把使用者從「過往報告」或「我的生字庫」強行切回最新文章。主動點擊「每日簡報」才返回最新版。
- 閱讀歷史文章時，不再錯誤顯示「今日缺稿」或排程故障；提醒區分真正過期的首頁與使用者選擇閱讀舊報告。
- 保留字庫、複習、閱讀進度、MC 答案、書面作答、匯入／匯出及保留離線文章的 PWA 既有行為。
- 更新正式網站版本、CSS／JS 查詢參數、Service Worker 版本及測試，讓 Safari 安裝版取得新版，**沒有清空使用者 localStorage**。

### 5. 發布守門與持續驗收

- 編輯品質、來源主題配對、備援主題多樣性、無網絡字義完整性列入 Python 回歸測試。
- 設有全歷史索引與文章結構驗證、Chromium／WebKit 模擬 iPhone／iPad 尺寸、已儲存的生字及測驗答案重新載入測試。
- 每日 07:05（香港時間）備援閱讀、07:40 AI 新聞、08:20 等缺稿補救及獨立公開核對照常運作；額外品質檢查預定 15:05 和 15:20。
- GitHub Actions 預設測試不升級 v16；未來正式功能版必須另行批准。

- 驗收記錄請查看 GitHub Actions：
  - https://github.com/Tom-gpt65/ai-daily-intelligence/actions/workflows/longform-validation.yml
  - https://github.com/Tom-gpt65/ai-daily-intelligence/actions/workflows/browser-v7.yml

  - https://github.com/Tom-gpt65/ai-daily-intelligence/actions/workflows/verify-pages.yml
- 測試通過的含義是**當前程式與模擬操作符合指定驗收規則**。尚未做到：逐句真人編輯、真實 iPhone/iPad 全型號測試、獨立核實所有 RSS 新聞、保證外部翻譯服務永久可用、保證 GitHub Actions 每天準時觸發、正式 Lighthouse 全項效能基準。
- **沒有系統可以永久保證無需任何後續維護。** v16 可作為目前正式使用基準；仍應保留每天自動健康檢查與版本不變的錯誤修正。
